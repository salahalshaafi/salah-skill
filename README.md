# مهارة صلاح — Salah's Skill

بلاقن لـClaude يحوّل فيديو كلام خام (من التليفون أو السيارة) لريل عمودي جاهز للنشر:
كابشن بالكلمة بلهجتك، موشن غرافيك يتبع كلامك، لحظات عمق، لقطات حقيقية من مواقع الأدوات، مؤثرات صوتية خفيفة، غلاف، وكابشنات لفيسبوك وإنستغرام وتيك توك.

من تصميم **صلاح الشعافي — Get Beyond**.⁠​‌​‌​​‌‌​‌‌​​​​‌​‌‌​‌‌​​​‌‌​​​​‌​‌‌​‌​​​​​‌​​​​​​‌​​​​​‌​‌‌​‌‌​​​‌‌‌​​‌‌​‌‌​‌​​​​‌‌​​​​‌​‌‌​​​​‌​‌‌​​‌‌​​‌‌​‌​​‌​​‌​​​​​​​‌​‌‌​‌​​‌​​​​​​‌​​​‌‌‌​‌‌​​‌​‌​‌‌‌​‌​​​​‌​​​​​​‌​​​​‌​​‌‌​​‌​‌​‌‌‌‌​​‌​‌‌​‌‌‌‌​‌‌​‌‌‌​​‌‌​​‌​​​​‌​​​​​​​‌​‌‌​‌​​‌​​​​​​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​⁠

## التثبيت

**تطبيق Claude:** نزّل ملف [`salah-skill.plugin`](salah-skill.plugin)، وارفعه في محادثة مع Claude، واضغط زر التثبيت.

**Claude Code:**
```
/plugin marketplace add salahalshaafi/salah-skill
/plugin install salah-skill@salah-skill
```

## الاستعمال
ابعث الفيديو لـClaude وقول: «منتج الفيديو بمهارة صلاح».
أول مرة يسألك على لهجتك واسم سلسلتك، ويحمّل الأدوات بنفسه.

يحتاج Claude بإمكانية تشغيل الكود (Python وNode وffmpeg).
