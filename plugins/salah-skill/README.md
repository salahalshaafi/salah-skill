# مهارة صلاح — Salah's Skill

من تصميم **صلاح الشعافي (Get Beyond)**

**مهارة صلاح** بلاقن لـClaude يحوّل فيديو كلام خام (من التليفون أو السيارة) لريل عمودي جاهز للنشر، بهوية بصرية خاصة بالمهارة:

- كابشن بالكلمة بلهجتك في كرت فاتح، والكلمة اللي تنطق تتلوّن
- موشن غرافيك يتبع كلامك جملة جملة
- لحظات عمق: كلمات تطلع من ورا راسك
- لقطات حقيقية من مواقع الأدوات اللي تذكرها، بدون واجهات مزيفة
- مؤثرات صوتية خفيفة، صوت مضبوط على ‎-14 LUFS
- غلاف، وملف ترجمة، وكابشنات لفيسبوك وإنستغرام وتيك توك

## الاستعمال
1. ثبّت البلاقن في Claude.
2. ابعث الفيديو وقول: «منتج الفيديو بمهارة صلاح».
3. Claude يسألك على لهجتك واسم سلستك (مرة وحدة)، ويبدأ.

يحتاج Claude بإمكانية تشغيل الكود (بيئة فيها Python وNode وffmpeg). أول مرة يحمّل الأدوات والموديلات بنفسه.
